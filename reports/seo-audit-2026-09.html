Recommendations

Ordered by priority · effort S = under 1 hour, M = a few hours, L = a day or more

1
HighEffort M
Target "Little Rock" in titles, headings, and service-page copy
Rewrite title tags to service + city, e.g. "Auto Insurance in Little Rock, AR | Patrick Borecky Insurance Agency". Expand Vehicle, Homeowners, and Life pages with coverage details, local context, and an FAQ block. Add a Commercial / Business page, a line listed on the About page with no page of its own. The recommended title tag, H1, and H2 sections for each page are in section 07.
Evidence: service pages carry 71–127 words; titles are single words ("Vehicle", "Homeowners", "Life"); "Little Rock" appears once on the homepage (footer address).
2
HighEffort S
Write a unique meta description for every page
One or two sentences, about 150 characters, naming the coverage, Little Rock / Central Arkansas, and a call to action with the phone number. Installing an SEO plugin (Yoast or Rank Math) adds a field for this on each page. A drafted meta description for all 10 recommended pages is in section 07.
Evidence: meta description tag absent on 7 of 7 pages; Lighthouse SEO audit flags it.
3
HighEffort M
Speed up the mobile homepage
Convert the hero image to WebP and preload it. Reduce web fonts to the 2–3 weights actually used. Enable Divi's critical-CSS and deferred-CSS options, or a caching plugin that does the same.
Evidence: mobile LCP 9.4s vs 2.5s target; hero image 390 KB; 23 font styles requested; render-blocking savings estimated at 2.2s.
4
HighEffort S
Add InsuranceAgency structured data to the homepage
JSON-LD with name, address, phone, hours (Mon–Fri 8:30 AM–5:30 PM), geo coordinates, service area, and sameAs links to the Farmers agent page, Facebook, and LinkedIn.
Evidence: 0 JSON-LD blocks on all 7 pages.
5
MediumEffort S
Set up measurement and keep the quote form on the site
Install Google Analytics 4 and verify the site in Google Search Console. Point the "Contact" menu item and "Request A Quote" buttons to /contact/, which already embeds the form, instead of the external Wufoo page. Track form submissions and phone-link taps as conversions.
Evidence: no Google Analytics or Tag Manager tag detected; nav "Contact" and both "Request A Quote" buttons open pboreckyinsurance.wufoo.com in a new tab; /contact/ is in the sitemap but not in the menu.
6
MediumEffort S
Fix heading structure
One H1 per page naming the service and city. Convert sub-sections ("Auto Insurance", "Boat Insurance", "How much coverage do you need?") to H2s. Remove empty H1s. Shorten the 120-character homepage H1.
Evidence: Vehicle has 6 H1s, Homeowners and Life 4 each; every inner page has an empty H1; Lighthouse flags heading order.
7
MediumEffort S
Add descriptive alt text to all images
Describe each image, e.g. "Patrick Borecky, Farmers Insurance agent in Little Rock, AR". Set in the WordPress Media Library.
Evidence: 18 of 18 images have empty or missing alt attributes.
8
MediumEffort S
Connect the site to the agent's other listings
Add boreckyagency.com as the website on the Google Business Profile, Facebook, LinkedIn, and Nextdoor listings, and request a website link on the Farmers agent page if Farmers allows it. Confirm the Facebook link in the site footer points to the active page.
Evidence: the Farmers agent page (5.0 rating, 34 reviews) links to email, LinkedIn, and Maps but not to boreckyagency.com. In a branded web search on September 18, the Farmers page, LinkedIn, Nextdoor, and Facebook appeared; boreckyagency.com did not appear in the results returned.
9
LowEffort S
Add Open Graph and social share tags
og:title, og:description, og:image, and og:url on each page so links shared by text, Facebook, or LinkedIn show a title, image, and summary.
Evidence: 0 Open Graph or Twitter card tags on all pages.
10
LowEffort S
Build out or remove the Refer A Friend page
Add the referral details and a form, or set the page to noindex and remove it from the sitemap.
Evidence: 3 words of body copy; the page is listed in the sitemap.
11
LowEffort S
Allow pinch-zoom and add a main landmark
Change the viewport tag to "width=device-width, initial-scale=1" and wrap page content in a <main> element.
Evidence: viewport sets maximum-scale=1.0, user-scalable=0; Lighthouse accessibility 82 mobile.
12
LowEffort S
Reference Farmers Insurance in visible copy
Add "Farmers Insurance" to the homepage heading or intro and the About page, following Farmers brand guidelines for agent websites.
Evidence: "Farmers" appears only in the email address and form URL; it is absent from all titles and headings. The Farmers agent page and Facebook page use "Farmers Insurance - Patrick Borecky".

Scope & method

What this report covers

Pages reviewed/, /about/, /vehicle/, /homeowners/, /life/, /contact/, /refer-a-friend/ (all URLs in /wp-sitemap.xml)
Speed dataLighthouse lab test of the homepage with simulated mobile throttling. Lab results vary run to run; Google's field data (Chrome user data) was not available for this site.
Keyword researchAbout 113 seed phrases covering the lines the agency lists, Little Rock and nearby cities, Farmers brand terms, and Arkansas topics (hail, tornado, flood, earthquake, state minimums). Each seed was run through Google's public autocomplete (US, English) on September 18–19, 2026. Head terms were also searched to see who ranks today.
Demand signalStrong = Google suggested the phrase in 2 or more separate lookups. Present = 1 lookup. Not in autocomplete = no suggestion came back, and the phrase stays only where the page needs it.
No search volumeNo keyword-volume tool (Google Keyword Planner, Ahrefs, Semrush) was connected. The demand signal shows that people search a phrase. It does not rank phrases by volume. Run the primary keywords through Keyword Planner before final sign-off if volumes are needed.
Not includedGoogle Search Console, Google Analytics, and Google Business Profile data (no access). Keyword rankings, search traffic, and backlink counts are not reported.
PlatformWordPress with the Divi 4.27.8 theme, served through Cloudflare. No SEO plugin detected.
Audit findings reflect the live site as crawled on September 18, 2026. Keyword research was run September 18–19, 2026.
